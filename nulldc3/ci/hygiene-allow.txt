# Where a tracked file of the emulator may name what looks like a machine (nulldc3/ci/hygiene.py, the test ci.hygiene).
#
# hygiene.py looks for a home directory of Linux, macOS or Windows, a path of WSL's network or of its drive mounts, a
# private IPv4 address and a .local host name in every tracked file, and every line that has one must be allowed
# here. One row per line, three fields separated by " | ":
#
#   <path> | <text> | <reason>
#
#   <path>     a tracked file as git names it, from the top of the tree, with "/"; "<dir>/**" is every file below <dir>
#   <text>     a piece of the line the row allows, copied from it (case and spaces count); "*": every line of the file
#   <reason>   why the line may say it: none of these names a machine of the project
#
# A row that allows no line any more fails the test too. A package that adds such a line adds its row in the same
# commit (PL-D79). The owner-specific patterns (PL-D61) are never written here: no row allows them.

# this list, which quotes the lines it allows

nulldc3/ci/hygiene.py | re.compile(r'/ | the check itself: the patterns it looks for
tests/ci/README.md | `ci.hygiene` | the test's documentation: the patterns it looks for
