# Where the tree may say "reicast": the history the rebrand keeps (the test rebrand.names; tests/rebrand/README.md).
#
# Every line of a tracked text file that says "reicast", in any case, must be allowed by an entry here, and every
# row must still find its line. One entry per line, four fields separated by " | ":
#
#   <path> | <pattern> | <class> | <reason>
#
#   <path>     a tracked file as git names it, from the top of the tree, with "/"; "<dir>/**" is every file below
#              <dir> (only with the pattern "*")
#   <pattern>  "*": the whole file (a whole path: no rows, and no check that it still says reicast); else a row:
#              a piece of the one line it allows, copied from that line (case and spaces count), that says reicast.
#              n rows with the same path and pattern allow n lines that have it, and need exactly n
#   <class>    one word, what kind of history it is: licence, record, origin, credit, provenance, header, marker,
#              legacy-dirs; and self for this test's own files
#   <reason>   why the line keeps the name
#
# Rows are sorted by path and, within a file, by line. A package that adds, moves, rewraps or deletes a line of
# history changes its row here in the same commit: find the row by the file's path and a piece of the line's text.
# Lines starting with "#" and empty lines are comments.
